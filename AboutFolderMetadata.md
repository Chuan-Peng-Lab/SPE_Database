## Folder Structure
	
Following the FAIR principle (Wilkinson et al., 2016), we adopted a three-level folder structure for the database: root folder, study folder, and experiment folder (if there are multiple experiments. Each level is accompanied by standardized metadata encoded in machine-readable JSON files, facilitating both human interpretation and computational accessibility. 

The root folder contains information spanning all studies included in the database. The study sub-folder contains information related to a specific study, defined as one or more experiments reported within a single publication, preprint, or thesis. The experiment folders include individual experimental data, typically representing a group of participants completing a specific version of the self-matching task across one or multiple sessions and assessment time points.

The root folder contains a master metadata file ("Dataset_inf.csv"), which serves as the primary index for the entire database, and study-specific sub-folders (e.g., "Amodeo_2024_CABN"). Each row in this file represents one study and is uniquely identified by a `Paper_Id`, which is the primary key across different folders of the database. Each column of "Dataset_inf.csv" corresponds to a metadata field of the studies, such as authors, publication year, journal name (where applicable), Digital Object Identifiers (DOIs). Importantly, the study-specific folder (`Folder_Name`) was included in "Dataset_inf.csv" for clear mapping between studies and their data folders.

The study-specific folder contains a JSON file, e.g., `Amodeo_2024_CABN.json`, and experiment-specific sub-folders. The JSON file contains study-level information such as theoretical background, participant recruitment strategies, participant recruitment procedures, as well as inclusion and exclusion criteria. The experiment-specific subfolders correspond to the individual experiments reported within the the study. However, if a study contains only a single experiment, the experimental-level data are stored in the study-level folder directly and no experiment-specific subfolder was created.
For those studies reported more than one experiment, each experiment has its own subfolders (e.g., `Exp1`, `Exp2`). Each experimental-level sub-folder include the following files: a CSV file for participants' demographic information (e.g., "Amodeo_2024_CABN_Exp1_raw_Subject.csv"), a JSON file for the experiment design (e.g., "Amodeo_2024_CABN_Exp1.json"), a CSV file for raw trial-level behavioral data file (e.g., "Amodeo_2024_CABN_Exp1_raw.csv"), a CSV file for the minimally preprocessed dataset (i.e., clean data, e.g., "Amodeo_2024_CABN_Exp1_Clean.csv"), and an xlsx file serves as the codebook for the clean data (e.g., "Amodeo_2024_CABN_Exp1_Clean.xlsx"). To facilitate efficient data retrieval and readability, all file names include four pieces of information — last name of the first author, publication year, journal abbreviation, and experiment identifier. Additionally, an optional fifth element specifies the content or function of the file (e.g., "_Subject" means information related to participants, "_raw" means unprocessed data from original studies). Together, these rules enhance data interoperability and facilitate large-scale secondary analyses.

## Standardization of the task implementation

To further facilitate cross-study integration of datasets, we developed a framework for standardizing the implementation of the self-matching task. This framework dissects the task into five parts: Physical Environment, Experimental Design, Block Structure, Trial Structure, and Stimulus Properties (Figure 2). These five parts zoom from the enviroment in which the experiment was done to the details of stimuli. Also, these details may also play a role in cognitive proccesses (e.g., Gold & Shadlen, 2007; Ratchliff et al., 2016), and allow nuanced cross-study analyses.

The Physical Environment variables, which were recorded in XXX,  describe the overall environmental conditions under which participants completed the task, including basic settings (e.g., laboratory-based vs. online administration), conditions relevant to multimodal stimulus presentation. For visual stimuli, these encompass viewing distance, monitor refresh rate, display resolution, brightness (Lin et al., 2023). For auditory stimuli, these include hardware specifications (e.g., headphones vs. speakers), sound pressure levels, and ambient noise (Kirk & Cunningham, 2025). These parameters determine how sensory information (e.g., visual or auditory signals) is physically presented to participants and they may modulate the sensory input of information processing (Bridges et al., 2020; Gold & Shadlen, 2007). 

The Experimental Design variables, which were recorded in XXX, define the structure of the study, including both between-subject factors (e.g., cultural group) and within-subject manipulations (e.g., Identity and Matching conditions). What distinguishes this level from the other levels is that design variables specify what is being manipulated and compared for hypothesis testing, rather than how the task is procedurally implemented, although these aspects may overlap. This distinction is consistent with established reporting guidelines that differentiate methodological details from inferential variables (Appelbaum et al., 2018).

The Block Structure variables, which were recorded in XXX, describe the block structure of the task, including number of blocks as well and details within a block: trial sequence and composition. Block Structure captures how multiple trials are organized within a block and often may strongly incluence the strategies adopted by participants (Bogacz et al., 2006) or result in serial dependency effect (Cicchini et al., 2024). Usually, trials in self-matching task are pseudo-randomized such that no more than three identical trial types are presented consecutively.

The Trial Structure variables, which were recorded in XXX, zoom in each trial and describe how each trial is implemented, including fixation duration, stimulus exposure, stimulus onset asynchrony (SOA), response window, and inter-trial interval (ITI). These parameters govern the temporal dynamics of stimuli presentation and are closely related to cognitive mechanisms such as evidence accumulation and response preparation (Ratcliff et al., 2016). 

Finally, the Stimulus Properties, which were recorded in XXX,  describe details of the stimuli, including their modality, their visual/auditory properties, and attributes of labels. The defining boundary of this level is whether a piece of information specifies what information is presented rather than how it is physically delivered, with the latter belong to Trial Structure.
